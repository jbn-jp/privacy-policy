Setup Guide – Tag Slug Updater

What is Tag Slug Updater?

Tag Slug Updater allows you to edit blog tag slugs in HubSpot — something that is not possible from the HubSpot dashboard. This is especially useful when tag names contain non-ASCII characters (e.g. Japanese) and you want clean, SEO-friendly URL slugs.

Requirements

  • A HubSpot account with access to Blog (CMS Hub or Marketing Hub Professional/Enterprise)
  • Permission to install connected apps in your HubSpot portal

Step 1: Connect the App

Click Install App on the HubSpot Marketplace listing. You will be redirected to HubSpot's OAuth authorization screen. Review the requested permissions and click Connect app.

Step 2: Edit Tag Slugs

  1. In HubSpot, go to Settings → Connected Apps → Tag Slug Updater → Settings tab
  2. Your blog tags will be listed with their current slugs
  3. Enter a new slug in the input field next to a tag. Slugs must contain only lowercase letters (a–z), numbers (0–9), and hyphens (-), and cannot start or end with a hyphen
  4. Click Save to apply the change

Step 3: Disconnect the App

To disconnect, go to HubSpot Settings → Integrations → Connected Apps, find Tag Slug Updater, and click Uninstall. This revokes the app's access to your portal.

Slug Format Rules

  • Lowercase letters (a–z), numbers (0–9), and hyphens (-) only
  • Cannot start or end with a hyphen
  • Examples: seo-tips, news2025, hubspot
